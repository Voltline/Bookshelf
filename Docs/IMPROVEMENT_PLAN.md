# Bookshelf 体验改进计划

本轮聚焦本地书架管理、批量导入与朗读体验，继续使用 SwiftUI / UIKit 原生控件和 Readium。

- [x] 书架：列表 / 封面网格、排序、阅读状态筛选、收藏。
- [x] 书籍详情：编辑书名作者、标记读完、查看格式、文件大小和导入时间。
- [x] 批量导入：逐本进度、失败明细，单本失败不终止整批。
- [x] 阅读：睡眠定时、准确的进度持久化、合并频繁写入及后台保存。
- [x] 验证：旧数据解码、筛选排序、导入失败隔离、数据持久化和 iOS 构建。

## 第三轮：导入与大书库搜索

- [x] 文件内容去重：SHA-256 分块校验；重复文件跳过，同名不同内容保留；重新导入最近删除的原书时恢复原记录。
- [x] 批量导入中止：完成当前文件后停止，保留已完成文件并报告未处理数量。
- [x] 全文搜索范围：全部书籍、收藏、正在读、自定义书单。
- [x] 搜索体验：可停止、显示进度及总命中数；每本先显示 20 条，按需展开；单本最多 200、单次最多 1000 条，并明确提示截断。
- [x] 验证：重复 / 改名 / 同名异版、旧 EPUB、恢复、取消导入、范围搜索、结果上限及旧任务隔离。

去重只认文件内容，不按书名作者猜测。旧 EPUB 可以从保留的原书计算校验值；旧 TXT 的原文件未保留，无法追溯其原始字节，因此该类旧数据首次重新导入可能仍会新增一本；新导入 TXT 均支持后续去重。不同编码或重新打包的文件不是字节相同的文件，不做有损合并。

## 第四轮：阅读记录与每日目标

- [x] 本地统计：阅读 / 听书分开计时、按本地日期汇总、今天 / 累计 / 单本记录。
- [x] 计时边界：正文可见且就绪后才统计，面板和后台暂停阅读，朗读独立统计，5 分钟无操作暂停，进程长时间挂起不追补。
- [x] 每日目标：默认 20 分钟，可关闭，可调整 5–240 分钟；不请求通知权限。
- [x] 原生页面：7 / 30 天 Charts 趋势、连续阅读天数、最近阅读书籍；入口在书架菜单，目标卡位于书架底部。
- [x] 数据保护：单独统计文件、15 秒检查点、退出 / 后台刷新、损坏文件不覆盖、手动确认清空；永久删除原书只保留匿名时长。
- [x] 验证：互斥计时、空闲 / 后台 / 面板 / 退出、跨日与时区边界、持久化 / 失败重试 / 匿名化、实际 ReaderView 计时和页面布局。

统计从本版本开始，不虚构此前阅读时长。连续阅读以每天合计至少 1 分钟计算，不等同于连续达标。统计仅保存在本机，不增加账号、遥测或联网服务。

补充 `PrivacyInfo.xcprivacy`：计时使用 SystemBootTime `35F9.1`；本机设置使用 UserDefaults `CA92.1`；沙盒 / 用户选择文件元数据使用 FileTimestamp `C617.1` / `3B52.1`。依据 [Apple Required Reason API 文档](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype)，只声明实际使用，不启用追踪。
